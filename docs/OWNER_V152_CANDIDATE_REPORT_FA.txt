۱. حفظ پروژه
هر دو کنترل قفل v150 روی فایل ورودی موفق بود (420 فایل، 395 دارایی، 201 پوستر).
تمام فایل‌های ورودی ZIP حفظ شدند؛ فقط ده فایل اصلی مشخص در گزارش اختلاف تغییر کرده‌اند.
تمام عکس‌ها، فونت‌ها، پوسترها، نسخه‌ها و فایل‌های آرشیو قدیمی byte-for-byte حفظ شده‌اند.
قفل‌های تاریخی v150 و اطلاعات نسخه فعال main بدون تغییر هستند؛ قفل جداگانه نسخه آزمایشی در design/owner-v152-candidate-lock.json قرار دارد.

۲. متون نهج البلاغه
796 فایل شماره‌دار، 1016 بخش متنی، 21,529,739 بایت (UTF-8)، همه با هش ثبت‌شده در mapping.csv یکسان.
تطبیق ساختاری با فهرست واقعی 1019 صوت: 982 موقعیت صوتی از نظر شماره و تعداد قسمت منطبق‌اند (از جمله 5 عنوان مشترک چند شماره‌ای).
37 موقعیت باقی مانده عمداً به متن حدسی متصل نشده‌اند: خطبه 97 (2 صوت، متن مستقل ندارد)، خطبه‌های 133، 148، 162 (هرکدام یک صوت بدون متن مستقل)، خطبه 138 (1 صوت در برابر 3 بخش متن)، نامه 31 (31 صوت در برابر 25 بخش متن). متن‌های موجود حتی برای موارد نامنطبق حذف نشده‌اند.
این تطبیق بر اساس شماره، ترتیب و تعداد قسمت در فهرست است، نه گوش دادن به همه فایل‌های صوتی.
بخش‌های توحید، دیدن خدا و کافی پنل متن دارند؛ متن واقعی این بخش‌ها هنوز ارائه نشده و پیام مناسب نمایش داده می‌شود.
پنل متن کشویی، بارگذاری محلی هنگام لمس، حافظه موقت محدود چهار شماره، جلوگیری از بارگذاری تکراری، خطای فایل و پاسخ دیرهنگام، بسته شدن با ضربدر و بازگشت، اسکرول عمودی و منع انتخاب و کپی معمولی دارد. این محدودیت کپی DRM نیست؛ متن در APK و ZIP قابل استخراج است.
تنظیم سرعت فقط برای پخش‌کننده صوت قرار گرفته، نه فیلم آپارات/ایتا یا کلیپ. جلسات ایتا برای دسترسی به پنل متن صفحه داخلی با دکمه باز کردن ایتا دارند؛ لینک اصلی همان است.

۳. صوت و پایداری
یکسان‌سازی پذیرش URL کافی برای شماره‌های 1 تا 999 با موتور Java و پنل، اصلاح لینک‌های دارای فاصله کدگذاری‌شده، حذف شنونده‌های رویداد بومی پس از خروج از کارت، جلوگیری از فرمان سرعت/مکث برای صوت دیگر در هنگام تغییر سریع جلسه، جلوگیری از شروع ناخواسته صوت با تغییر سرعت در حالت مکث، عدم ثبت زمان بافر به عنوان شنیدن، توجه به نتیجه درخواست Audio Focus، امکان لغو صوت در حال آماده‌سازی و اصلاح چند API سازگار با Android 6.
اصلاحات Java هنوز با SDK واقعی اندروید کامپایل و روی دستگاه تست نشده‌اند.

۴. محتوای آنلاین و آرشیو
جلسات 18 و 19 دیدن خدا از رکوردهای واقعی و هش‌شده revision 2 داخل سورس قرار گرفتند. آزمون محلی جلوگیری از تکرار، پذیرش جلسه جدید، رد revision قدیمی و حفظ مطالب داخل برنامه موفق بود.
آرشیو آزمایشی هر هفت بخش در scripts/archive_owner_all_sections_v152.py آماده شد؛ از scope مستقل استفاده می‌کند تا آرشیو قدیمی تغییر نکند. آزمون محلی هفت بخش، حفظ تاریخچه، هش تصاویر و رد rollback موفق بود. اتصال به Cloudflare، اجرای زمان‌بندی‌شده واقعی و تولید APK آینده از کل هفت بخش انجام نشده است. سازوکار قدیمی فعال روی main هنوز دست‌نخورده است.
اصلاح Worker در هر دو شکل ماژول و تک‌فایلی: محدودیت واقعی بایت درخواست و پاسخ فهرست، اعتبارسنجی نشانی و حفظ تصویر مورد استفاده چند مطلب. آزمون هر دو روی KV شبیه‌سازی‌شده موفق بود. هیچ Deploy انجام نشده است. محدودیت ذاتی KV در نوشتن همزمان چند مدیر، مقابله با حملات ورود و جداسازی WebView از iframeهای خارجی هنوز نیازمند طراحی/آزمون محیط واقعی است؛ ادعای امنیت کامل نداریم.

۵. ساخت و آزمون
versionCode 152، versionName 1.0.2 (پیشنهادی)، applicationId رسمی بدون تغییر. شناسه Debug مستقل قبلی حفظ شد. هیچ کلید یا رمز جدیدی وارد پروژه نشده است.
همه آزمون‌های scripts/run_v152_local_checks.sh با exit code 0 پایان یافتند؛ جزئیات در OWNER_V152_LOCAL_TEST_RESULTS.txt. این‌ها آزمون‌های کد، داده، شبیه‌سازی Worker/bridge، کنترل Java یادآور با stub و آزمون محاسبات ساعت هستند؛ نه تست کل APK.
تلاش برای مرورگر واقعی با ERR_BLOCKED_BY_ADMINISTRATOR محیط متوقف شد. تست UI در tests/v152_browser_smoke.py برای محیط مجاز باقی است. Gradle و Android SDK در محیط فعلی نصب نبودند؛ APK ساخته نشده، امضا نشده و پذیرش بازار تأیید نشده است.
Workflow مستقل owner-v152-candidate-ci.yml برای ساخت Debug بدون کلید انتشار اضافه شده ولی اجرا نشده. Workflowهای تاریخی v150 و قفل‌های main عمداً تغییر نکرده‌اند؛ پیش از ادغام نهایی باید تنظیمات فعال و مسیر ساخت محتوای نسخه جدید به صورت کنترل‌شده مهاجرت کنند.

۶. کارهای باقی مانده
بازگشت اتصال GitHub، ایجاد/تطبیق شاخه آزمایشی با PR قبلی، اجرای Gradle و بررسی APK Debug روی گوشی؛ کنترل تماس و جداشدن هندزفری، باتری، اینترنت، عملکرد واقعی متن و سرعت، و امنیت پل WebView. تکمیل متن‌های نامنطبق و متن سه مجموعه دیگر. بررسی نسخه جدید Cloudflare و آرشیو هفت بخش با داده واقعی و راه‌اندازی زمان‌بندی بدون آسیب به آرشیو قبلی. پس از تأیید مالک و بررسی گواهی امضای قدیمی، ساخت Release رسمی.
این ZIP کامل را در یک محل امن نگهداری کنید. مستقیم جایگزین main یا APK نصب‌شده نکنید. چون متن‌ها در ZIP کامل‌اند، اگر انتشار عمومی آنها مجاز نیست، پیش از بارگذاری عمومی GitHub تصمیم مالک لازم است.
